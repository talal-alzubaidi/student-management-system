Student Management System

This is a simple Student Management System I built using Python to practice what I’ve learned.

The program runs in the terminal and lets the user add students, view their grades, calculate the average grade, and search for a student.

Features

* Add a student with a name and grade
* Show all students and their grades
* Calculate the average grade
* Search for a student by name
* Exit the program

What I Used

* Python
* Lists and dictionaries
* Functions
* Loops
* If/else statements

How to Run

Make sure Python is installed, then run:

python main.py

Notes

Student information is stored in a list while the program is running. The data is not saved when the program closes.
